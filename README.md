# Credit-Card-Default-Risk-Analytics
Project Overview

This project analyzes credit card customer data to understand default patterns, repayment behaviour and credit exposure.

The objective is to identify customer segments associated with higher default rates and provide actionable insights to support credit risk management decisions.

Business Problem

Financial institutions need to monitor customer repayment behaviour and identify segments that may require additional credit risk monitoring.

This project uses historical customer and repayment data to examine these patterns through an interactive Power BI dashboard.

Dataset

Source: UCI Machine Learning Repository

Dataset: Default of Credit Card Clients

Records: 30,000 customers

Target Variable: Default Payment Next Month

Geography: Taiwan

Period: April–September 2005

Dataset: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
